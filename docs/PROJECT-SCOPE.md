# Project Scope

## Academic context

- Institution: Albukhary International University (AIU)
- Programme: Computer Science
- Project: HR & NLP CV Summarizer
- Supervisor: Dr. Bashir
- Contribution: student, FYP contributor and designer

## Problem being explored

Reviewing CVs one by one can be slow and inconsistent. The project explores a structured way to summarise and rank a small set of CVs against a common set of review dimensions.

## Bounded scope

The intended portal is designed for fewer than 10 CVs at a time. The project scope is deliberately small and academic; it is not represented as a production recruitment platform.

## Seven dimensions

| Dimension | Review focus |
|---|---|
| Qualifications | Academic and professional qualifications |
| Experience | Relevant work and experience |
| Location & Relocation | Current location and relocation context |
| Soft and Hard Skills | Interpersonal and technical capabilities |
| References | Reference information |
| Personal Information | Relevant candidate profile information |
| Rewards | Awards and recognitions |

## Academic milestone

The ERD was approved for university submission. Cloudflare Pages and Workers were considered as possible hosting options; no deployment is claimed.
